# Implementation Skill

Esta skill instrui o agente *Leo (Lead Fullstack)* a:
1. Executar estritamente o escopo definido na Task e na Spec associada.
2. Não desviar da arquitetura acordada.
3. Gerar os testes automatizados correspondentes para validação.
