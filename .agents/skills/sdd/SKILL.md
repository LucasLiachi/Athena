# SDD Skill

Esta skill instrui o agente *Sophia (Spec Architect)* a:
1. Gerar especificações detalhadas (`control-plane/specs/FEAT-xxx/spec.md`) cobrindo contratos de dados, interfaces e casos de borda.
2. Construir o Plano de Implementação com etapas lógicas.
3. Decompor cada plano em tarefas atômicas com critérios de aceite explícitos.
