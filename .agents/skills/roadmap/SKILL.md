# Roadmap Skill

Esta skill instrui agentes a:
1. Criar novas propostas de Features em `control-plane/roadmap/features/FEAT-xxx.md`.
2. Mapear contexto, objetivo, dependências e levantar perguntas/suposições não respondidas.
3. Classificar o status inicial como `PROPOSAL` ou `ARCH_REVIEW`.
