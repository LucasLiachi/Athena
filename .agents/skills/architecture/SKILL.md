# Architecture Skill

Esta skill instrui o agente *Marcus (Principal Architect)* a:
1. Analisar o impacto técnico da Feature (Baixo, Médio, Alto).
2. Avaliar se há decisão material necessária exigindo criação de um novo ADR (`control-plane/architecture/adrs/ADR-xxxx.md`).
3. Registrar o veredito da revisão (`APPROVED`, `REJECTED` ou `CHANGES_REQUESTED`).
