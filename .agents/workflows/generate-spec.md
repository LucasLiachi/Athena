# Workflow: Generate Spec (SDD)

1. A Spec Architect (*Sophia*) assume a Feature aprovada.
2. Redige a especificação formal técnica com schemas, contratos e edge cases.
3. Cria o Plano de Implementação associado.
4. Quebra o plano em tarefas atômicas (`Task`) com critérios de aceite explícitos.
5. Move o status para `PLAN_READY`.
