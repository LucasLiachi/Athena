# Workflow: New Feature Proposal

1. Receba a ideia ou necessidade do usuário.
2. Formate uma nova Feature em `control-plane/roadmap/features/FEAT-xxx.md`.
3. Preencha objetivo, contexto, levante perguntas abertas e suposições.
4. Registre no banco de dados operacional SQLite (`Feature`, `FeatureQuestion`, `FeatureAssumption`).
5. Transfira o status para `ARCH_REVIEW` e notifique o Principal Architect.
