# Workflow: Architecture Review

1. O Principal Architect (*Marcus*) avalia a Feature pendente.
2. Identifica impacto (Baixo, Médio, Alto) e decisões fundamentais.
3. Se houver decisão material, redige o ADR em `control-plane/architecture/adrs/ADR-xxxx.md`.
4. Emite o veredito (`APPROVED` / `CHANGES_REQUESTED`).
5. Se aprovado, move a Feature para `SPEC_DRAFTING`.
