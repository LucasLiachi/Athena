# Passo: Log Time

Este passo é responsável por acionar o agente do Jira para analisar o que foi feito no dia e registrar (logar) o tempo gasto em cada tarefa (issue) correspondente no Jira.

## Instruções

1. Leia as notas ou commits do desenvolvedor.
2. Identifique a Issue correspondente no Jira.
3. Registre as horas de trabalho.
